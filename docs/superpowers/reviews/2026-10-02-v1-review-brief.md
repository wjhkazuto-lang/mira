# Mira v1 外部代码审查说明

> 给第二位审查者（例如 GPT）的说明。把整个仓库交给它，再附上这份文件。

## 项目是什么

Mira 是一个单用户、运行在本机的 AI 朋友，有分层的长期记忆。技术栈：Python 3.12 + FastAPI + SQLite + 不需要构建的 HTML/JS。聊天模型用 DeepSeek（OpenAI 兼容接口、JSON 模式），语义检索用本地的 fastembed（`BAAI/bge-small-zh-v1.5`）。

- 设计文档（以它为准）：`docs/superpowers/specs/2026-10-02-mira-design.md`
- 实施计划：`docs/superpowers/plans/2026-10-02-mira-v1.md`
- 代码入口：`mira/main.py`（组装各模块）、`mira/chat.py`（对话编排）、`mira/writer.py` 和 `mira/reflector.py`（后台记忆任务）
- 运行测试：`uv run pytest -q`（当前 166 passed，1 skipped；前端：`node --test tests/web/sync.test.js`；跳过的那个需要设置 `RUN_SLOW=1` 并联网下载模型）

## 已经做过的审查

Claude Opus 5.5 做过一次完整审查，结论是"修复后可以合并"。下面这些问题都已经修复，并且有测试覆盖，**不需要再报**：

- API 路由改成 async，避免和事件循环在不同线程里共用同一个 sqlite 连接、导致事务交错
- WebSocket 校验 Origin，HTTP 加了 TrustedHost 和跨站写请求拦截（防跨站劫持、DNS 重绑定）
- 聊天出现任何未预期的异常时，都会给前端发错误事件；向量维度不一致时不再报错；开发模式默认使用单独的数据库
- LLM：超时 60 秒；4xx 错误（429 除外）不重试；key 错误、余额不足时给出明确的中文提示
- 模型返回的 JSON 被截断时，会尽量捞出已经完整的消息
- 写入器分批处理、截短超长消息、`max_tokens` 改为 4000；相对日期按消息发出的日期换算
- 核心档案改用第三人称，避免 Mira 把档案里的"你"当成自己
- 历史记录会截短超长消息，不会挤掉更早的上下文
- 后台循环不会因为一次出错就停掉；路径一律相对项目根目录解析；WebSocket 重连后会补上漏掉的消息

## 第二轮审查（Codex）已修复

- 聊天里出现 `{{…}}` 会让提示词渲染报错、记忆整理永久卡住
- 删除记忆后编号被复用，导致证据指向不相关的内容（改用 AUTOINCREMENT，数据库版本号设为 1）
- 并发发消息或重试会触发重复的模型调用（加锁串行处理）
- 反思期间用户手动改的档案被覆盖；反思结果用了过时的证据集合
- 历史快照与实时消息竞争导致气泡丢失或重复（按编号合并；用户消息带 client_id 确认，多个标签页会同步）
- 记忆更新后来源没有跟着更新；记忆页旧响应覆盖新标签；状态保存失败后界面没有恢复

## 已知但暂不处理的小问题（不用重复报告）

- 启动补跑和凌晨 4 点的定时反思可能在同一天各跑一次
- 写入器的同一批操作里，如果两个操作改同一个 id，可能留下孤立的记忆
- 聊天上下文里"模式·出现 N 次"会把已删除的证据也算进去
- 删除一条"替代了旧记忆"的新记忆后，旧记忆仍然处于已过时状态
- 只改承诺状态也会锁定这条记忆

## 请重点看

1. **异步与状态机**：`mira/chat.py` 里的批次开关、取消与重试流程、`_wait_then_respond` 的计时逻辑。有没有竞态会导致重复回复、漏回复，或者回复存进了错误的批次？
2. **花钱的路径**：有没有任何代码路径可能反复调用付费 API（写入器、反思器、重试、调度器）？
3. **隐私与安全**：除了 Origin/Host 之外，还有没有能让本机其他网页或进程读到聊天和记忆的途径？静态文件路由有没有路径穿越的问题？
4. **提示词**：`personas/*.md`、`mira/prompts/*.md` 是否实现了设计文档 §4.1 的全部规则（特别是 comfort / raise_issue / crisis 三种情况）？有没有措辞会让模型编造记忆，或者在用户情绪很差时说教？
5. **数据完整性**：`mira/store.py` 的嵌套事务、`Writer.run` / `Reflector.run` 里先算向量再进事务的顺序。出错时会不会丢数据或者产生重复记忆？
6. **前端**：`web/chat.js`、`web/memory.js` 有没有 XSS（应该全部使用 textContent）、中文输入法问题、断线时的状态错误？
