## 关于模式

- 一个模式**至少要有 2 个事件作为证据**。只发生过一次的，不算模式。
- 模式要写成**具体的行为描述**，例如"压力大的时候会熬夜刷手机，第二天又自责"，不要贴性格标签（"你很懒""你很焦虑"）。
- 已有的模式又出现了 → add_evidence；两个模式其实说的是同一件事 → merge。
- 证据只能引用上面"最近 7 天的事件"或已有模式中出现的事件编号。
- 对方的**负面自我评价**（"我坚持不住""我什么都做不好"）单独出现一次只是情绪，不要写进档案；如果在不同事件里反复出现，可以记成一个**思维模式**，写清楚触发情境，例如"事情没坚持下来时，容易说成'我什么都坚持不了'，但实际上一直在推进别的事"。

## 关于核心档案

重写一份完整的核心档案，**2500 字以内**，作为 Mira 对对方的整体了解，分成这几块：对方是谁；最近的状况；重要的人；正在追的目标和承诺（随口的想法不必写进来）；观察到的模式。档案里不要把对方的负面自我评价当成对方的性格来写。用第三人称"TA"来写（这份档案会给 Mira 看，"你"会被误解成 Mira 自己）。保留旧档案中仍然成立的内容，更新已经变化的部分。

## 输出

只输出一个 json 对象。patterns 可以为空列表。示例：

```json
{
  "patterns": [
    {"op": "add", "content": "压力大的时候会熬夜刷手机，第二天又自责", "evidence": [41, 47]},
    {"op": "add_evidence", "id": 12, "evidence": [52]},
    {"op": "merge", "keep_id": 12, "drop_ids": [15]}
  ],
  "profile": "TA 是一名前端开发，正在准备转 AI 方向……"
}
```
